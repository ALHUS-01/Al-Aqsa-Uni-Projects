# 🍔 Food Delivery Database System

A database design project developed for the Database Systems course at Al-Aqsa University. This project focuses on designing and building a relational database schema for a food delivery application.

## 🛠 Technologies Used
* **Query Language:** SQL (DDL, DML)
* **Database Design:** EER Diagram modeling

## 🗄️ Database Architecture (Schema)
The `fooddeliverydb` database is structured around the following core entities:
* **Customers:** Stores user details (Name, Phone, City, Account Status).
* **Restaurants:** Manages restaurant profiles, cuisine types, ratings, and delivery fees.
* **MenuItems:** Links specific food items and their prices to their respective restaurants.
* **Drivers:** Manages delivery personnel details and vehicle types.
* **Orders & OrderDetails:** The central tables linking customers, restaurants, and drivers, while tracking item quantities, total amounts, and order statuses.

## 📂 Project Structure & Attachments
* SQL scripts used to build the database schema and insert data.
