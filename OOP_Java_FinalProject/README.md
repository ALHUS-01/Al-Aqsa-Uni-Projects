# 📚 Library Management System - OOP Java

A software project developed during my Computer Science studies at Al-Aqsa University. This system simulates core library operations and management through a console-based interface.

The system architecture is based on the attached UML class diagram.

## 🛠 Technologies & Concepts Used
* **Programming Language:** Java
* **Environment:** Visual Studio Code (Java Extension Pack)
* **OOP Concepts:**
  * **Inheritance:** `Student` and `Author` classes inherit from the base `Person` class.
  * **Abstraction:** The `Person` class is implemented as an abstract class.
* **Data Management:** Utilizes `ArrayList` for in-memory data storage, with File I/O implementation (`saveData()` and `loadData()`) for persistent storage.

## ✨ System Features
* **Book Management:** Add, delete, update quantities, and search for books.
* **Student Management:** Register and remove students, and deposit funds into their accounts (`depositMoney`).
* **Transactions:** Process book purchases (`buyBookMenu`), calculate total revenue, and track sold books.
* **Statistics:** Generate and print system reports (`printStatistics`).
